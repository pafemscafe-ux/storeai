STOREAI — VS CODE PROJECT

1. Extract this ZIP folder.
2. In VS Code, choose File > Open Folder.
3. Select the extracted StoreAI_VSCode_Project folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose Open with Live Server.
   Otherwise, double-click index.html to preview it in your browser.

The app is responsive and its main workspace is constrained to the screen height with internal scrolling.
Product data is stored locally in the browser. Real store connections need official API authorization and a backend.
